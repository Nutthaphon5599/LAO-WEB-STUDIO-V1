# Lao Web Studio — Netlify Ready

## Deploy by drag and drop
1. Extract the ZIP file.
2. Open Netlify → Add new site → Deploy manually.
3. Drag the extracted folder into Netlify.

## Deploy from GitHub
Upload all files to the root of a GitHub repository, then connect that repository to Netlify.
- Build command: leave empty
- Publish directory: `.`

The contact form uses Netlify Forms and will appear under Site → Forms after the first deployment.
